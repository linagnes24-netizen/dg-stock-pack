# dg-stock-pack

遊戲網址：https://linagnes24-netizen.github.io/dg-stock-pack/

- `index.html`：股力全開遊戲本體（GitHub Pages 發布）
- `og.png`：分享到 LINE／FB 時的預覽圖

小 DG「股力全開」遊戲的每日收盤價資料包。

- `data/latest.json`：上市＋上櫃市值前 100 檔，前一交易日收盤價
- 每天台北時間 06:20 由 GitHub Actions 自動更新（08:50 補跑）
- 手動更新：Actions → 每日更新收盤價資料包 → Run workflow
